CURL TEST CURL TEST SUITE - Task Management System
Module: CMS3407
Base URL (local): http://localhost:3000
Note: Commands are for Windows PowerShell (curl.exe). JSON bodies are
stored in body files to avoid quoting problems.


TASK SERVICE

TEST 1 (Right): GET all tasks
Command:
curl.exe -i http://localhost:3000/tasks
Expected: HTTP 200 OK and a JSON array.
Actual: HTTP 200 OK and a JSON array of tasks.
Result: PASS

TEST 2 (Wrong): GET on a misspelt route
Command:
curl.exe -i http://localhost:3000/tassks
Expected: HTTP 404 Not Found and {"error":"Route /tassks not found"}
Actual: HTTP 404 Not Found and {"error":"Route /tassks not found"}
Result: Fail 

TEST 3 (Right): POST a new task
body_post.json contains: {"title":"Buy milk"}
Command:
curl.exe -i -X POST http://localhost:3000/tasks -H "Content-Type: application/json" --data "@body_post.json"
Expected: HTTP 201 Created and {"id":1,"title":"Buy milk","completed":false}
Actual: HTTP 201 Created and {"id":1,"title":"Buy milk","completed":false}
Result: PASS

TEST 4 (Wrong): POST with missing title
